# Business Insights 360 – Power BI Dashboard

## Project Overview
Business Insights 360 is an interactive Power BI dashboard built for AtliQ Hardware, a global computer peripherals company. The organization relied heavily on static Excel reports, which limited visibility into performance and slowed decision-making. This dashboard enables stakeholders to monitor KPIs and analyze trends across departments.

## Business Objective
To provide a centralized, data-driven reporting solution that supports informed decision-making across Finance, Sales, Marketing, Supply Chain, and Executive leadership.

## Key Features
- Department-wise analytical views
- Executive summary dashboard
- Dynamic KPIs and trend analysis
- Optimized performance using DAX Studio

## Dashboard Views
- Finance View
- Sales View
- Marketing View
- Supply Chain View
- Executive View

## KPIs Tracked
- Net Sales
- Gross Margin %
- Net Profit %
- Forecast Accuracy
- Net Error
- Absolute Error

## Data Sources
- Excel / CSV files (Targets, Market Share data)
- MySQL Database (Fact & Dimension tables)

## Tools & Technologies
- Power BI Desktop
- DAX & DAX Studio
- SQL & MySQL
- Excel

## Key Learnings
- Data modeling using star schema principles
- Writing optimized DAX measures
- Performance tuning using DAX Studio
- Designing stakeholder-focused dashboards
- Publishing and managing reports in Power BI Service
